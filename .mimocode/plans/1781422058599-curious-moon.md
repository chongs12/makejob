# TTS 场景回退实施计划

## 目标

对齐单体架构，实现 TTS 三级回退机制：
1. **第一级**：Live2D 模型绑定的 TTS 配置
2. **第二级**：场景默认 TTS 配置（companion/interview）
3. **第三级**：全局 fallback Provider

## 架构设计

```
CompanionUseCase.Chat()
    │
    └─ synthesizeSpeech()
        │
        ├─ 优先: sceneTTSService.SynthesizeForScene(scene, modelKey, text)
        │         └─ 内部三级回退:
        │            第一级: Live2DModel.TTSConfigID → TTSConfig
        │            第二级: AdminConfig["tts_default_xxx_config_id"] → TTSConfig
        │            第三级: fallbackProvider (YAML 配置)
        │
        └─ 降级: 如果 sceneTTSService 失败 → 直接使用 ttsClient
```

## 数据模型

### TTSConfig 表 (tts_configs)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uint | 主键 |
| name | string(100) | 音色名称 |
| engine | string(32) | 供应商引擎 (volcengine/minimax/xiaomi_mimo) |
| voice_id | string(100) | 音色 ID |
| auth_config_json | text | 鉴权配置 JSON (api_key, group_id, app_id 等) |
| params_json | text | 额外参数 JSON (model, format, sample_rate 等) |
| is_active | bool | 是否启用 |
| sort_order | int | 排序顺序 |
| created_at/updated_at/deleted_at | timestamp | 时间戳 |

### Live2DModel 表 (live2d_models)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uint | 主键 |
| name | string(100) | 模型名称 |
| scene | string(20) | 使用场景 (interview/companion) |
| model_url | string(500) | 模型文件 URL |
| tts_config_id | *uint | 绑定的 TTS 配置 ID (可空) |
| is_active | bool | 是否启用 |
| created_at/updated_at/deleted_at | timestamp | 时间戳 |

### AdminConfig 表 (admin_configs)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uint | 主键 |
| config_key | string(100) | 配置键 (tts_default_companion_config_id) |
| config_value | text | 配置值 (TTSConfig ID) |
| created_at/updated_at | timestamp | 时间戳 |

## 实施步骤

### Step 1: 添加数据库模型

**文件**: `app/companion/internal/biz/tts_config.go`

定义 TTSConfig 和 Live2DModel 领域模型。

### Step 2: 添加仓库接口

**文件**: `app/companion/internal/biz/tts_repo.go`

定义三个仓库接口：
- `TTSConfigRepo` - TTS 配置 CRUD
- `Live2DModelRepo` - Live2D 模型查询
- `AdminConfigRepo` - 场景默认配置查询

### Step 3: 实现场景 TTS 服务

**文件**: `app/companion/internal/biz/scene_tts.go`

实现 `SceneTTSService` 接口：
- `SynthesizeForScene(ctx, req) -> TTSResult`
- `resolveProvider(scene, modelKey) -> TTSProvider`
- 三级回退逻辑

### Step 4: 实现 TTS Provider 工厂

**文件**: `app/companion/internal/data/tts_factory.go` (扩展)

添加 `NewTTSProviderFromConfigRecord(record) -> TTSProvider` 方法。

### Step 5: 实现仓库

**文件**: `app/companion/internal/data/tts_config_repo.go`
**文件**: `app/companion/internal/data/live2d_model_repo.go`
**文件**: `app/companion/internal/data/admin_config_repo.go`

### Step 6: 更新配置

**文件**: `app/companion/internal/conf/conf.go`

添加数据库连接配置（已有）。

### Step 7: 更新 CompanionUseCase

**文件**: `app/companion/internal/biz/companion.go`

- 添加 `sceneTTSService` 依赖
- 更新 `synthesizeSpeech` 方法使用场景回退

### Step 8: 更新 main.go

**文件**: `app/companion/cmd/server/main.go`

创建仓库和服务实例，注入到 CompanionUseCase。
