# 修复 POST 接口 500 错误

## 根因分析

所有 POST 接口 500 的共同根因：**AI Gateway 的 `prompt_templates` 表为空**。

错误传播链路：
```
AI Gateway biz 层查询 prompt_templates → 空表 → ErrPromptRenderFailed (Kratos Internal)
  → 下游服务 fmt.Errorf 包装 → 丢失 gRPC 状态码
    → biz 层 kratosErr.InternalServer 包装
      → Gateway grpcErrorToHTTP → 500 "internal error"
```

受影响接口（全部依赖 AI Gateway）：
- `POST /api/v1/companion/chat` → CompanionAgent
- `POST /api/v1/plans` → PlanAgent
- `POST /api/v1/interviews` → InterviewAgent
- `POST /api/v1/questions/:id/submit` → QuizAnalyzer

## 修复方案

### Fix 1: 种子数据 — `prompt_templates` 表（根因修复）

**文件**: `app/ai_gateway/internal/data/data.go`

在 `NewData` 函数中，AutoMigrate 之后添加种子数据插入逻辑：
- 查询 `prompt_templates` 表是否为空
- 如果为空，插入 4 个场景的默认 Prompt 模板：
  - `interview` — Go 面试官
  - `companion` — 学习伙伴
  - `quiz` — 刷题助手
  - `plan` — 学习计划生成器

模板内容复用单体后端 `docs/backend/internal/model/seed.go:775-807` 的种子数据。

**新建文件**: `app/ai_gateway/internal/data/prompt_seed.go`
- `func seedDefaultPrompts(db *gorm.DB) error`
- 包含 4 个 `biz.PromptTemplate` 结构体
- 字段映射：`TemplateContent` → `TemplateText`，`Variables` → `VariablesJSON`

### Fix 2: Question service 增加 `toGRPCError`

**文件**: `app/question/internal/service/question.go`

添加 `toGRPCError` 函数（与 companion/interview service 一致）：
```go
func toGRPCError(err error) error {
    if kratosErr.FromError(err) != nil {
        return err
    }
    return kratosErr.InternalServer("INTERNAL", err.Error())
}
```

将所有 `return nil, err` 改为 `return nil, toGRPCError(err)`。

### Fix 3: Plan service 修复空操作 `toGRPCError`

**文件**: `app/plan/internal/service/plan.go:293-298`

当前实现只是 `return err`，改为：
```go
func toGRPCError(err error) error {
    if err == nil {
        return nil
    }
    if kratosErr.FromError(err) != nil {
        return err
    }
    return kratosErr.InternalServer("INTERNAL", err.Error())
}
```
