# 修复 Growth 页面 "Cannot read properties of undefined (reading 'length')" 报错

## 问题分析

`GrowthPage.tsx` 中有 **5 处** 在渲染路径中直接访问 `.length`，但未使用可选链 (`?.`)。当后端返回的字段为 `undefined` 或 `null` 时，页面崩溃。

此外还有 **2 处** 在 click handler 中对 `focus_signals` 做 `.map()` / `.flatMap()` 也未加防护，点击按钮时也会崩溃。

## 需要修改的文件

**前端（必修）：**
- `frontend-react/apps/web/src/features/growth/GrowthPage.tsx`

**后端（加固，可选但推荐）：**
- `app/gateway/internal/proxy/handler.go`

## 修复方案

### 1. 前端修复 — `GrowthPage.tsx`（5 处渲染崩溃 + 2 处点击崩溃）

| 行号 | 当前代码 | 修复 |
|------|---------|------|
| **888** | `growthSummaryQuery.data.recent_study_logs.length` | → `growthSummaryQuery.data.recent_study_logs?.length` |
| **924** | `growthSummaryQuery.data.recent_interviews.length` | → `growthSummaryQuery.data.recent_interviews?.length` |
| **963** | `growthSummaryQuery.data.recent_plans.length` | → `growthSummaryQuery.data.recent_plans?.length` |
| **692** | `theme.focus_tags.length` | → `theme.focus_tags?.length` |
| **704** | `theme.suggestions.length` | → `theme.suggestions?.length` |
| **517** | `growthSummaryQuery.data.focus_signals.map(...)` | → `(growthSummaryQuery.data.focus_signals \|\| []).map(...)` |
| **518** | `growthSummaryQuery.data.focus_signals.flatMap(...)` | → `(growthSummaryQuery.data.focus_signals \|\| []).flatMap(...)` |
| **560** | `growthSummaryQuery.data.focus_signals.map(...)` | → `(growthSummaryQuery.data.focus_signals \|\| []).map(...)` |
| **561** | `growthSummaryQuery.data.focus_signals.flatMap(...)` | → `(growthSummaryQuery.data.focus_signals \|\| []).flatMap(...)` |

### 2. 后端加固 — `handler.go`

在 `normalizeGrowthSummaryPayload` 中，除了保证 4 个顶层数组字段存在外，还需处理 `null` 值（protojson 可能输出 `null` 而非省略字段）。当前 `ensureArrayField` 已处理 `null` case（`existing != nil` 判断），所以顶层字段是安全的。

但 `normalizeWeeklyFocusPayload` 只保证 `themes` 数组存在，未处理每个 theme 内部的 `focus_tags` 和 `suggestions`。需要增加嵌套字段的保护：

```go
func normalizeWeeklyFocusPayload(value interface{}) interface{} {
    payload, ok := value.(map[string]interface{})
    if !ok {
        return value
    }
    ensureArrayField(payload, "themes")
    if themes, ok := payload["themes"].([]interface{}); ok {
        for _, raw := range themes {
            if theme, ok := raw.(map[string]interface{}); ok {
                ensureArrayField(theme, "focus_tags")
                ensureArrayField(theme, "suggestions")
                ensureArrayField(theme, "related_question_sets")
            }
        }
    }
    return payload
}
```

## 验证方式

1. 启动前端和后端服务
2. 访问 `http://localhost:3101/growth`
3. 页面应正常渲染，不再报 "Something went wrong"
4. 检查浏览器控制台无 `Cannot read properties of undefined` 错误
5. 测试以下场景：
   - 新用户（无学习记录）→ 应显示空状态占位文案
   - 有学习记录的用户 → 应正常展示数据
   - 后端部分服务不可用时 → 页面应降级展示，不崩溃
