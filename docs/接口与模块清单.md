# MakeJob 接口与模块清单

本文档基于当前代码状态更新于 `2026-05-15`，仅记录当前真实存在的主路由和模块边界，避免继续参考旧草案。

## 1. 后端入口

### 1.1 API 服务

- 启动文件：`backend/cmd/server/main.go`
- 健康检查：`GET /api/health`

### 1.2 Worker

- 启动文件：`backend/cmd/worker/main.go`
- 当前负责：
  - 异步抓取导入任务
  - 异步题目流水线生成任务

## 5. 当前模块归属建议

### 5.1 如果你要查后端主流程

优先看这些目录：

- `backend/internal/handler`
- `backend/internal/service`
- `backend/internal/repository`
- `backend/internal/model`

### 5.2 如果你要查前台业务页

优先看这些目录：

- `frontend-react/apps/web/src/features`
- `frontend-react/apps/web/src/shared`
- `frontend-react/apps/web/src/state`

### 5.3 如果你要查后台内容生产链路

优先看这些目录：

- `frontend-react/apps/admin/src/features`
- `backend/internal/service/admin_*`
- `backend/internal/handler/admin_handler.go`
- `backend/internal/handler/scraper_handler.go`

## 6. 当前不要再做的错误假设

- 不要再假设前台只有占位页。
- 不要再假设 AI 面试只有文本提交。
- 不要再假设题目流水线只有后端接口、没有后台页面。
- 不要再假设异步任务没有独立 worker。
